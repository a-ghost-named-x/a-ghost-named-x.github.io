About

I run end-to-end infrastructure for a multi-building manufacturing organization: servers, identity, networking, endpoints, security, and the internal applications that sit on top.

I came into IT through cybersecurity, so security is a design input for me, not a cleanup task. When something breaks, I chase the root cause instead of the symptom, then automate the fix so it stays fixed.

The goal behind all of it: turn reactive IT into documented, proactive operations.

How this site works

Hand-written HTML and CSS, plus a few kilobytes of vanilla JavaScript for the terminal. No framework, no build step, no cookies, no trackers.

GitHub Pages serves it straight from the main branch, and the custom domain resolves through Cloudflare DNS. A strict Content Security Policy means the only files a browser will load are this site's own.

Every push and pull request runs CI: the W3C Nu validator checks the HTML and lychee checks the links, internal and external. CI checks the site. It never deploys it.
